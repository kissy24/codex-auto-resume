# codex-auto-resume

macOS 上で Codex CLI のセッションを監視し、利用上限で止まった作業を、枠の回復後に同じ会話・作業ディレクトリで一度だけ再開するためのツールを開発しています。

現在は設計段階です。初版では、ユーザーが指定したセッションを macOS の LaunchAgent で監視し、利用者が先に作業を再開した場合は自動再開の予約を取り消す予定です。最初の実機検証では、利用上限による停止理由を別プロセスから取得できるか確認します。

予定している CLI の操作、状態遷移、実装順、受け入れ条件は[設計書](docs/design.md)にまとめています。
